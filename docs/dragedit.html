내 맥 안의 AI가 같이 일해요

A local AI works with you

  • What is it? 문서를 놓으면 요약이 바로 써져요. Tab을 누르면 심층 분석. 계약서의 함정 조항도 잡아요.
  • OCR 오타수정 불확실한 단어만 AI에게 보내요. 고친 곳은 검토 창에서 하나씩 보고 적용해요.
  • ⌥ Space 글자 팝업 어느 앱의 글자든 그 자리에서 고쳐요. 규칙으로 되는 일은 AI 없이 바로 끝나요.
  • Ollama · LM Studio 계약서도 회의록도 내 컴퓨터 밖으로 나가지 않아요. 클라우드는 직접 켰을 때만.
  • What is it? Drop a document and a summary writes itself. Tab for a deep dive. It even spots risky contract clauses.
  • OCR typo fix Only uncertain words go to the AI. Review each fix before it's applied.
  • ⌥ Space text popup Fix text in place, in any app. Rule-based jobs finish instantly without AI.
  • Ollama · LM Studio Contracts and notes never leave your Mac. Cloud only if you turn it on.
AI

필요할 때만. 내 맥에서 먼저.Only when needed. Local first.

규칙으로 되는 일은 AI를 부르지 않아요. 애매한 것만 내 컴퓨터의 AI(Ollama·LM Studio)가 처리하고 클라우드는 직접 켰을 때만 써요. 밖으로 나갈 땐 휠에 미리 표시돼요. Rules handle what rules can. Only the fuzzy parts go to an AI on your Mac (Ollama, LM Studio). Cloud is opt-in, and the wheel tells you before anything leaves.

What is it?

문서를 놓으면 요약이 바로 써져요. Tab을 누르면 심층 분석. 긴 글은 나눠서 읽어요.

Drop a document and the summary writes itself. Tab for a deep dive. Long text is read in parts.

OCR 오타수정

OCR typo fix

문서 전체가 아니라 인식이 불확실한 곳만 AI에게. 고친 곳은 검토 창에서 하나씩 확인.

Only uncertain words go to the AI, not the whole page. Review every fix before saving.

Text popup ⌥ Space

어느 앱에서든 글자를 고르고 ⌥ Space. 줄바꿈 정리부터 말로 하는 요청까지 그 자리에서.

Select text in any app and press ⌥ Space. From fixing line breaks to plain-language requests, in place.
