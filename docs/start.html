1. 설치1. Install

3분이면 끝나요.Done in three minutes.

  1. 1

    설치 파일 받기Download

    GitHub 릴리스에서 Hanlabong-버전.pkg를 받아요. macOS 26 이상, Apple silicon 맥.Get Hanlabong-version.pkg from the GitHub release. macOS 26+, Apple silicon.

  2. 2

    처음 열 때 경고 넘기기Get past the first warning

    아직 애플 공증 전이라 경고가 떠요. 시스템 설정 › 개인정보 보호 및 보안 맨 아래에서 그래도 열기를 누르면 설치 마법사가 열려요.It is not notarized yet. In System Settings › Privacy & Security, scroll down and click Open Anyway.

  3. 3

    애드온 고르기Pick add-ons

    설치 마법사의 "사용자화"에서 Hanlabong PDF · Developing을 고를 수 있어요. 나중에 다시 설치해도 돼요.Under Customize in the installer, choose Hanlabong PDF and Developing. You can add them later too.

  4. 4

    손쉬운 사용 권한 켜기Turn on Accessibility

    처음 켜면 안내 창이 떠요. 다른 앱의 글자를 읽고 바꾼 글자를 다시 넣으려면 맥의 손쉬운 사용 권한이 필요해요. 글자는 내 맥 밖으로 나가지 않아요.A guide appears on first launch. Reading and replacing text in other apps needs macOS Accessibility access. Text never leaves your Mac.

켜지면 메뉴 막대에 한라봉 아이콘이 생겨요. 아이콘 › 설정…(⌘ ,)에 에이전트 · API 키 · 일반 탭이 있어요.Once running, a Hanlabong icon sits in the menu bar. Icon › Settings… (⌘ ,) has the Agents · API Keys · General tabs.

2. AI 준비2. Set up AI

둘 중 하나만 하면 돼요.Pick one of two.

파일 바꾸기와 휠은 AI 없이도 다 돼요. 글자 팝업의 "말로 부탁하기", What is it? 요약, PDF 빈칸 채우기·목차 같은 일에 AI가 필요해요.Converting and the wheels work without AI. AI powers plain-language requests, What is it? summaries, PDF form filling and contents.

A · 추천Recommended

Ollama — 내 맥에서 무료로Ollama — free, on your Mac

  1. ollama.com/download에서 Ollama를 받아 설치하고 켜요.Install and open Ollama from ollama.com/download.
  2. 터미널에서 모델을 받아요(아래 표에서 내 맥에 맞는 것):Pull a model in Terminal (pick one from the table):ollama pull gemma4:12b
  3. 한라봉 설정 › 에이전트에서 받은 모델을 골라요. 끝.Choose it in Hanlabong Settings › Agents. Done.

글이 내 맥 밖으로 나가지 않아요. 계약서·신청서처럼 개인정보가 든 문서엔 이쪽을 써요.Nothing leaves your Mac. Use this for contracts and forms with personal info.

B · 맥이 가벼울 때For lighter Macs

Groq — 무료 API 키Groq — free API key

  1. console.groq.com에 가입해요. 카드 등록 없이 돼요.Sign up at console.groq.com. No card needed.
  2. API Keys에서 Create API Key. gsk_로 시작하는 키는 한 번만 보이니 바로 복사해요.In API Keys, click Create API Key. The key starts with gsk_ and is shown once, so copy it now.
  3. 한라봉 설정 › API 키에서 클라우드 AI 사용을 켜고 Groq 칸에 붙여 넣어요. 키는 맥 키체인에 저장돼요.In Hanlabong Settings › API Keys, turn on Use cloud AI and paste it into Groq. It is stored in your Keychain.
  4. 에이전트 탭이나 PDF 요청칸의 칩에서 Groq를 골라요.Pick Groq in the Agents tab or the chip in the PDF ask box.

무료라도 1분·하루에 쓸 수 있는 양이 정해져 있어요(콘솔의 Limits에서 확인). 글이 Groq 서버로 가요.The free tier has per-minute and per-day limits (see Limits in the console). Text goes to Groq’s servers.

3. 이렇게 쓰면 좋아요3. Ways to use it

대학생 하루에 한라봉 넣기.A student day, with Hanlabong.

과제를 PDF로 제출Submit as PDF

과제.docx·한글 파일을 끌다가 ⇧ › PDF. 용지·단·줄 간격 그대로. 원본은 그대로 남아요.Drag essay.docx or a Hangul file, ⇧ › PDF. Paper, columns and spacing kept; the original stays.

한글 파일 못 열 때Can’t open a .hwp

조교가 보낸 .hwp를 끌다가 ⇧ › PDF나 Word로. 맥에 한글이 없어도 돼요.Drag the .hwp from your TA, ⇧ › PDF or Word. No Hangul app needed.

장학금·근로 서류 채우기Fill scholarship forms

Hanlabong PDF에서 "내 정보로 채워줘". 서명은 트랙패드로. 내 정보는 한 번만 넣어 두면 돼요.In Hanlabong PDF, ask "fill it with my info" and sign on the trackpad. Save your info once.

수특·문제집 답 맞추기Check answers in study books

문제 쪽에서 해설 단추 한 번, 되돌아가기로 원래 자리. "9단원 해설로 가줘"도 돼요.One click from a problem to its explanation and back. Or ask "go to unit 9 answers".

강의 자료 스캔 정리Clean up scanned notes

사진 찍은 필기를 ⇧ › 글자 넣은 PDF. 반듯하게 펴고 검색되게.Photographed notes, ⇧ › searchable PDF. Flattened and searchable.

조별 과제 회의록Group meeting notes

어디서든 글자를 고르고 ⌥ Space › "문장 다듬어줘", "할 일만 뽑아줘".Select text anywhere, ⌥ Space › "tidy this", "list the to-dos".

계약서·약관 미리 보기Read contracts first

자취방 계약서를 휠 ⌘ › What is it?. 요약과 조심할 조항을 먼저 짚어 줘요.Drop a lease on ⌘ › What is it? for a summary and clauses to watch.

포트폴리오 사진Portfolio photos

사진을 ⇧ › JPG › 웹용(2MB 이하·위치 삭제), 클라이언트 샘플은 워터마크까지.Photos, ⇧ › JPG › Web (under 2 MB, location removed), or a watermarked sample.

발표 자료 용량 줄이기Shrink slide decks

메일에 안 붙는 PDF·영상은 ⌘ › 용량. 크기 그대로 용량만.PDFs or videos too big to email, ⌘ › Shrink. Same size, smaller file.

5. 막힐 때5. If you get stuck

자주 묻는 것.Common questions.

"API 키가 만료됐거나 맞지 않아요"라고 떠요"The API key expired or is wrong"

그 서비스의 키가 만료됐어요. 새 키를 받아 설정 › API 키에 다시 넣거나, 설정 › 에이전트에서 Ollama 모델로 바꿔요. PDF 요청칸의 칩에서도 바로 바꿀 수 있어요.Get a new key and paste it in Settings › API Keys, or switch to an Ollama model in Settings › Agents or the PDF ask-box chip.

"Ollama가 꺼져 있어요""Ollama isn’t running"

Ollama 앱을 켜요. 메뉴 막대에 라마 아이콘이 보이면 돼요. 모델을 처음 쓸 땐 메모리에 올리느라 조금 더 걸려요.Open the Ollama app (the llama icon in the menu bar). The first request loads the model, so it takes a bit longer.

너무 느려요It’s slow

한 단계 작은 모델(예: gemma4:12b → gemma4:e4b)로 바꿔 봐요. 두꺼운 책 목차는 한 번 만들면 이 맥에 저장돼서 다음부터는 바로 떠요.Try a smaller model (e.g. gemma4:12b → gemma4:e4b). A book’s contents are saved after the first time and open instantly later.

글자 팝업이 안 떠요The text popup doesn’t open

시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용에서 한라봉이 켜져 있는지 봐요. 설정 › 일반 › 권한에서 바로 열 수 있어요.Check System Settings › Privacy & Security › Accessibility for Hanlabong. Settings › General › Permissions opens it.

그래도 안 되면Still stuck?

위쪽 메뉴의 문의로 메일을 보내거나 GitHub에 남겨 줘요.Use Contact in the top menu to email or open a GitHub issue.
