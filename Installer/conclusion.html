설치 완료 · Installed

  1. 응용 프로그램에서 한라봉을 열어요. 메뉴 막대에 아이콘이 생겨요.
    Open Hanlabong from Applications. An icon appears in the menu bar.
  2. 안내 창이 뜨면 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용에서 한라봉을 켜요(글자 팝업용).
    Turn on Hanlabong in System Settings › Privacy & Security › Accessibility (for the text popup).
  3. AVI·MKV·WebM 같은 영상 형식까지 쓰려면 터미널에서 brew install ffmpeg.
    For AVI, MKV, WebM and more: brew install ffmpeg.
